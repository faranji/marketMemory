# Market Memory Türkiye

Explainable Borsa İstanbul event analysis. The first MVP focuses on TUPRS and combines KAP disclosures, TUPRS/XU100 prices, Brent, USD/TRY, multilingual NLP, historical analogues, abnormal returns, confidence and abstention.

This repository is a **guided scaffold**, not a finished black-box project. Most files explain what to build, why it exists, expected inputs/outputs, leakage risks and tests.

Start with `START_HERE.md`.
