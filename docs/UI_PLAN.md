# UI Plan

## Overview
Real data coverage, latest reviewed disclosures, market context and source health.

## Event Analysis
Event identity → evidence message → KPI cards → analogue distribution → TUPRS/XU100 event window → macro context → expandable analogues → confidence/abstention → source/methodology.

## Historical Analogues
Filters, research table, 1D/3D/5D abnormal outcomes, source links and comparison.

## Data Quality & Methodology
Sources, pipeline stages, failures, formulas, versions, leakage rules and limitations.

## UI rule
Streamlit reads clean data. It never scrapes sources, trains models or writes raw records.
