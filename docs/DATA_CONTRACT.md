# Data Contract

## Raw KAP
source, external ID, URL, fetch time, publication time, visible text, raw HTML path, content hash.

## Clean event
title, body, publication timestamp, publisher, category, source URL, revision flags, review and leakage status.

## Price
asset, trade date, OHLC, adjusted close, volume, provider.

## Feature
Only pre-event data: lagged returns, Brent/USDTRY change, volatility, relative volume, market regime.

## Outcome
Future labels only: asset, benchmark and abnormal returns for 1D/3D/5D.
