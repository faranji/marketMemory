# Project Scope

Market Memory Türkiye retrieves historical KAP events similar to a selected TUPRS disclosure and reports their 1/3/5 trading-day benchmark-adjusted outcomes under comparable market conditions. It shows sources, uncertainty and data quality.

The MVP does not provide buy/sell advice, causal claims, guaranteed predictions, real-time trading or full BIST coverage.

Expansion: TUPRS → energy sector → sector adapters → BIST 30/100 → optional social sources → global adapters.
