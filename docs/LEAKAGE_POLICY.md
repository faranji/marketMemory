# Leakage Policy

1. Analogue candidates must be earlier than the query event.
2. Rolling features must be shifted.
3. Future returns are labels, never inputs.
4. Use chronological splits.
5. Fit transforms only on train.
6. Keep revisions together.
7. Exclude texts that already state the market outcome.
8. Social content after event time cannot be a predictor.
9. Tune thresholds before the final test period.
10. UI must separate evidence from prediction.
